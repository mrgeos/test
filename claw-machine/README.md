# Хватайка — 3D-симулятор автомата с игрушками

Браузерный симулятор claw machine на **three.js** с физикой **cannon-es**. Призы — настоящие физические тела:
они лежат кучей, толкаются, цепляются друг за друга, выскальзывают из клешни и падают в шахту выдачи.

## Запуск

```bash
cd claw-machine
npm install
npm run dev        # http://localhost:5173
npm run build      # статическая сборка в dist/
npm run preview    # посмотреть сборку локально
```

Сборка использует относительные пути (`base: './'`), поэтому `dist/` можно выложить на любой статический хостинг,
например GitHub Pages, в том числе в подпапку.

## Управление

| Действие | Клавиатура | Экран |
| --- | --- | --- |
| Двигать клешню | `WASD` / стрелки | джойстик слева внизу |
| Опустить клешню | `Пробел` / `Enter` | кнопка «Хватай» |
| Добавить 5 жетонов | `C` | кнопка «+5» |
| Вращать камеру вокруг автомата | тянуть мышью | вести пальцем по автомату |
| Перейти к следующей стороне автомата | `V` / `E`, назад `Q` | быстрый свайп или кнопка с камерой |
| Приблизить / отдалить | колесо мыши | щипок двумя пальцами |
| Вернуть вид спереди | двойной клик | двойной тап |
| Звук вкл/выкл | `M` | кнопка с динамиком |
| Окно с видом сбоку | `P` | настройки |

Направления джойстика привязаны к камере: «вверх» всегда значит «от себя», с какой бы стороны вы ни смотрели.
Если отпустить камеру рядом с одной из сторон, она сама доводится ровно на неё.
На раунд даётся 30 секунд, потом клешня опускается сама.

## Режимы хватки

- **Лёгкий** — если клешня обхватила игрушку, она её донесёт.
- **Честный** — сила хватки зависит от того, насколько точно вы попали по центру и сколькими лапками захватили игрушку.
- **Как в ТЦ** — как у настоящих автоматов: наверху хватка слабеет и лапки чуть разжимаются,
  а «щедрый» раунд выпадает тем чаще, чем дольше вы проигрываете.

## Как это устроено

```
src/
  main.js      рендерер, пост-обработка (bloom), свет, игровой цикл с фиксированным шагом физики 1/120 с
  config.js    размеры автомата, скорости клешни, параметры режимов сложности
  cabinet.js   корпус, стекло, шахта выдачи, пульт с джойстиком и LED-табло, лампочки, комната
  claw.js      портал, каретка, трос, раскачивание и трёхпалая клешня (кинематические тела)
  prizes.js    процедурные игрушки (мишки, зайки, котики, утята, пингвины, звёздочки, мячики, подарки, капсулы)
  game.js      конечный автомат раунда, захват, выигрыши, жетоны
  cameras.js   орбитальная камера (вращение, свайпы, зум) и окно «картинка в картинке»
  input.js     клавиатура и сенсорный джойстик
  audio.js     звуки, синтезированные через WebAudio (без аудиофайлов)
  hud.js       интерфейс поверх 3D-сцены
```

Раунд проходит по состояниям: `play → open → descend → settle → close → grip → ascend → top → return → release → reset`.

Как работает захват:

1. Клешня опускается, пока не упрётся в игрушку сверху, в пол или в бортик шахты.
2. Каждая лапка сжимается отдельно и останавливается, когда упирается в игрушку, которая не поддаётся.
   Так ведёт себя катушка настоящей клешни, когда доходит до предела усилия.
3. Игрушки, которых коснулись хотя бы две лапки (или одна, если игрушка точно по центру), считаются захваченными.
   Качество захвата зависит от числа лапок, от смещения от центра и от типа игрушки: мячик скользкий, утёнок цепкий.
4. На подъёме к захваченной игрушке прикладывается «сила хватки»: поддержка против гравитации и пружина к центру клешни.
   Если хватка слабее веса, игрушка держится только на лапках и может выскользнуть при раскачивании.

Все размеры указаны в метрах. Автомат стоит в начале координат, его лицевая сторона смотрит в сторону `+Z`.
